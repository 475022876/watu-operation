# P2 实施说明

日期：2026-11-02。分支：`codex/employee-experience-p2`。起点：`c5127952fa7d9e627846bb5299fd521d44dcc6f3`。

## 改动与目的

只新增 `prototypes/employee-workspace/` 及本报告目录，把 P1 静态设计变成可操作原型：

- 我的任务：按待办、退回、待审核和截止日期找下一步，简化任务创建，隐藏技术对象。
- 创作工作区：讨论和当前作品并列；候选需明确选用；保存和送审仅作用于作品及选定附件。自由创作可保存到已有任务或新建任务。
- 作品审核：冻结作品版本、意见和修订历史放在同一流程；专业审核与发布审批保持独立；作者不可自审。
- 保存失败、版本冲突及结果未知时保留草稿并阻止旧内容送审；品牌切换后丢弃旧生成结果。
- 中文/英文界面切换、移动端作品切换、键盘焦点与对话框操作。

## 代码职责

| 文件 | 职责 |
| --- | --- |
| `src/model.ts` | 合成数据、模拟权限、版本、故障及审核状态机 |
| `src/main.tsx` | React 三页面、任务交接、模拟情境与本标签页草稿 |
| `src/style.css` | 桌面双栏、移动切换、工作区滚动与固定操作 |
| `tools/serve.mjs` | 仅静态文件、回环地址监听、主机名校验、CSP、无 API 代理 |
| `tests/model.test.mjs` | 本地模型测试 |
| `tools/browser-test.mjs` | 真实 Chrome 自动操作，但数据与业务结果均为模拟 |
| `tools/isolation-test.mjs` | 静态服务隔离测试 |

模型中的角色、签名比较、未知结果查询和版本锁只用于验证交互规则，不能作为生产授权或幂等实现。P3 必须以服务端当前身份、权限和版本为权威。

## 保留边界

没有改动原业务路由、正式 API、数据库、生产配置、Workspace、PG Migration 或应用版本。未安装第三方业务系统，未接入收费 AI 或真实发布。六个业务分区仅保留导航；本轮未实现的页面明确提示原型范围，不宣称完整系统重构完成。

## 回滚

原 MOS 可继续独立运行。停止本原型 Node 进程即可撤除预览；仅清除浏览器键 `vfib-p2-synthetic-workspace-v1` 会删除本原型合成状态，不影响 MOS。代码通过撤销本分支新增文件提交回滚，或返回起点提交；不得对存在用户修改的目录执行强制重置。本轮未产生业务数据迁移或正式存储回滚需求。
