# 下一阶段前置条件

P2 工程原型及自动检查已完成，可进入人工试用；未启动 P3。

正式业务接入前需要人工确认：

1. 员工能否从任务进入制作、选定作品并送审，审核员能否退回并定位反馈；记录试用结果后确认页面结构。
2. 首批接入范围、角色及品牌；服务端提供当前权限与 allowedActions，演示角色切换不得进入正式应用。
3. 现有 API 与作品模型的映射，冻结版本、附件授权、专业审核和发布审批边界；结构性冲突应单独评审，不擅改契约。
4. 保存的版本检查、请求关联、未知结果查询及重复提交幂等，需要真实服务端实现和故障验证。sessionStorage 模拟方案不能替代它们。
5. 正式文件上传、扫描、访问权限、模型读取能力与外发授权分开实现；当前仅文件元数据演示。
6. 正式 AI Provider、授权、预算和调用账本继续经过现有安全边界；本阶段未请求密钥或产生收费调用。
7. 真实集成隔离数据副本、原有 17 套回归、Phase 1/2 安全测试、浏览器及回滚验收。

建议 P3 先接“我的任务 → 现有作品保存/审核”最小纵向流程，再接 AI。维持正式 JSON 权威状态，PostgreSQL 切换属于另外批准的数据库实施范围；不引入双写。图片、视频与发布执行保持独立后续工作，不把原型按钮视为功能已实现。
