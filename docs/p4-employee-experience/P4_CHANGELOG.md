# P4 变更说明

代码提交：`82f473b6a8ce343a2e264d9cf9fc7bf815ce2a66`。基线：`95c24deaff853eb310deea0f99953fcb8d0a0f88`。分支：`codex/employee-experience-p4`。

## 员工工作区

沿用 P3 真实 API 试点，不增加业务中心或第二套数据权威。

- 保存任务、品牌、视图与指定作品版本的入口链接；刷新可以回到原工作上下文。服务端重新校验对象，跨品牌链接拒绝，版本不属于当前任务时阻断。
- 返回原入口保留任务链接；未保存作品、处理中请求、未知结果，以及未保存的讨论或输入，都有离开确认。取消离开保留原输入。
- 单独解析本地草稿，验证 actor / brand / task、正文结构、附件 ID、基础版本和未知结果标记；缓存中的权限字段不作为权威。损坏缓存不会覆盖服务端作品。
- 作品读取失败时关闭编辑能力，核对服务端结果后明确采用，避免显示可写的空白稿。
- 生成请求增加同步锁，快速重复点击不产生重复作业；Ctrl/Cmd+Enter 发送，组合输入事件不发送。
- 英文切换更新文档语言并在本标签页刷新保持；用户正文、文件名、任务标题和意见不翻译。
- 移动端视图按钮声明当前选择；送审弹窗有名称与说明，默认焦点为“返回修改”，Escape 关闭后回到送审按钮；页面切换焦点落在主工作区。

主要文件：`prototypes/employee-workspace/src/p3/main.tsx`、新增 `draft.ts`。

## 测试与预览

`tools/mos-ui-check.js` 按已采用的六区菜单和真实二级入口操作，保留原业务验证。`tools/p3/` 三个测试工具支持独立证据目录；浏览器测试增加稳定等待、构建新鲜度检查及 P4 情境。新增 `tools/p4/` 的草稿、并发测试和隔离预览工具。

## 保留与未改动

没有修改 `lib/` 业务源码、正式 API、Workspace、数据库结构、Provider 策略、预算、审批权限、正式资产入库、依赖或应用版本。Master Topic、研究、日历、视频、历史审核和旧入口继续保留。讨论仍不写入任务或审批，也不在刷新后恢复；离开前明确告知。未知创建结果继续禁止自动重放，不冒充已经新增请求关联 API。
