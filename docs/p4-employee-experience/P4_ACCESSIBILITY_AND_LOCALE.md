# 键盘、语言与窄屏

代码提交 `82f473b6a8ce343a2e264d9cf9fc7bf815ce2a66`。验证命令：`node tools/p3/browser-test.cjs`（P4 证据目录）；32/32 通过。

| 项目 | 实际结果 | 限制 |
| --- | --- | --- |
| Ctrl+Enter 发送 | 实际 Chrome 键盘事件触发一次本地生成作业 | Cmd 路径由相同处理器实现，未在 macOS 实机验证 |
| 输入组合状态 | isComposing 合成事件不发送 | 未以 Windows 系统中文输入法实机验收 |
| 连续双击 | 一个生成请求，不自动重试 | 不能代替服务端全系统幂等 |
| 送审弹窗 | 有可访问名称/说明，初始焦点为返回修改，Escape 退出并恢复焦点 | 未做屏幕阅读器和完整 WCAG 审计 |
| 页面焦点 | 切页主区域可聚焦，保持既有可见焦点样式 | 人工键盘全流程仍需试用 |
| 窄屏 | Chrome 390px 仿真无横向溢出，作品/讨论切换保留输入并声明当前选择 | 未使用真实手机及软键盘 |
| 中英文 | document.lang 正确，选择在刷新后保持，正文不被翻译 | 用户生成内容和文件名不翻译；登录原入口仍按自身语言策略 |
| 离开保护 | 取消返回旧入口或切任务，未保存作品/讨论输入保留 | 确认离开后讨论不恢复，已保存作品与本标签页草稿规则分别适用 |
