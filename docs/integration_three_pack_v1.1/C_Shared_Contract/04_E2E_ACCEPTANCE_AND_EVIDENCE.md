# 联合验收矩阵（同一隔离联调环境）
| ID | 验收场景 | PASS必须具备的证据 |
|---|---|---|
| INT-01 | 双进程/独立数据目录与真实HTTP | 两端启动日志、URL脱敏、请求ID对应及网络响应 |
| INT-02 | Ed25519签名/重放/失效服务账号 | 正常成功；无效签名、过期、nonce重放、吊销一律拒绝 |
| INT-03 | 受限用户票据及品牌/密级 | 实际用户作用域内成功、跨品牌/高密级失败，提供方审计ID |
| INT-04 | 最终特殊审批 | 普通P1/管理员无权；由**真实授权人**（独立权限）批准；Mock身份不得计正式通过 |
| INT-05 | 资产准入端到端 | 三必填字段、复核记录、稳定幂等键、入库返回真实Asset ID/version；失败不可复用 |
| INT-06 | 检索与版本 | Approved资产/知识/Skill当前版本查得且受权；历史Skill只读不可直接新复用 |
| INT-07 | 撤回与事件 | Provider撤回→Consumer收到事件、缓存失效、后续调用被拒；断线与截断恢复 |
| INT-08 | Published Archive不镜像 | 发布快照在MOS留存；资料库无自动新增；提取母版须另行独立申请 |
| INT-09 | SPECIAL-01正式字典 | 完整原件、校对清单、批准证据；缺材料=BLOCKED，不以想象填充 |
| INT-10 | 正式Skill | 原件入库、人工批准、生效、MOS获取生效hash并记录生成快照 |
| INT-11 | 真实文字/图片AI | 供应商真实响应、模型ID、脱敏调用日志、结果保存、成本/计费；无凭据=BLOCKED |
| INT-12 | P1–P4浏览器实际操作 | 真实浏览器、屏幕截图/录屏、关键点击、失败路径；无浏览器=NOT_RUN |
| INT-13 | 两边完整回归、安全及备份 | 两边exit code、失败详情、恢复验证；不得只引用单方报告 |
| INT-14 | 版本和共同签署 | 两方Commit、OpenAPI hash、部署版本、测试清单、联合报告双方确认 |

**统一结果值：** PASS / FAIL / BLOCKED / NOT_RUN / NOT_APPLICABLE（要写理由）。无真实外部条件不能记PASS；失败数为零不等于通过。`JOINT_ACCEPTANCE_REPORT.md`应按每项列出方法、日志路径、运行时间、参与进程、版本及阻断责任。
