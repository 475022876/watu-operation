> 选题 / 英文文案 / 视频脚本」五类产出和出图链路完整跑一遍。本手册的路径全部走**厂商免费额度**，

>
> 核实日期：**2026-10-20**（额度与价格由厂商随时调整，**以你控制台的实际显示为准**；

## 1. 三条零付费路线（按推荐顺序）

| 路线 | 免费档 | 适合 | 关键限制 |
| --- | --- | --- | --- |
| **智谱 GLM**（首选） | `GLM-4.7-Flash` / `GLM-4-Flash` **长期免费不限量**；新账号另赠 2000 万 tokens | 五类文本产出、效果评估、反复调提示词 | 免费档有速率上限；峰值时段可能排队 |
| **阿里云百炼**（备选，质量更高） | 新用户**每个模型 100 万 tokens**，90 天内有效；各模型额度独立 | 想看 `Qwen` 系列在长文报告上的表现 | 限速偏紧（每分钟 20 次、并发 2）；需实名才能继续超出后付费 |
| **硅基流动 SiliconFlow** | 注册赠代金券 + 一批 0 元小模型 | 同一份材料横向对比多个开源模型 | 小参数模型质量有限，别用它下最终结论 |

> **图像**：智谱 `CogView-3-Flash` 同样是免费档，可直接验证出图链路（本版已支持，见 §4）。
>
> **视频**：**没有可用的免费档**。火山方舟 Seedance 按秒计费（720P 约 0.18 元/秒），
> 建议把视频放到最后一步，等文本与图像都验收通过再开。

### 一条要避开的"免费"陷阱

火山方舟的「协作奖励计划」（每日 200 万 tokens 返还）**要求授权把你调用的输入输出内容
用于模型/算法优化**。对**公开资料、个人学习**没问题；但本系统处理的是品牌与营销材料，
**这条授权与我们的数据外发策略冲突**——不要为了让视频/文本免费而打开它。
需要火山方舟时，走「安心体验」的一次性额度（每模型 50 万 tokens）或直接按量付费。

## 2. 五分钟接上（以智谱为例）

1. **注册并拿 Key**：`open.bigmodel.cn` → 注册 → 控制台「API Keys」→ 新建。
   Key 只在创建时完整显示一次，复制存好。
2. **打开系统**：`http://127.0.0.1:9080/mos` → 侧边栏底部「系统接入」→「大语言模型」卡。
3. **按下表填**（接入方式选错会导致把 Key 发到错误的主机，我们的出站校验会拦，但没必要试）：

| 字段 | 值 |
| --- | --- |
| 接入方式 | **智谱 GLM（有免费档）** |
| 端点 | `https://open.bigmodel.cn/api/paas/v4` |
| 模型 | `glm-4.7-flash` |
| 密钥 | 粘贴刚建的 Key |
| 超时 | 60000（免费档偶尔慢，留足） |
| 重试 | 1 |

4. **保存** → 密钥框立即清空，卡片上只剩 `••••••1a2b` 与指纹；就绪度变 `CONFIGURED_NOT_TESTED`。
5. **点「测试连接」**：这是一次**真实的**最小调用（`max_tokens=16`），走完整闸门
   （数据分级 → 预算 → 端点校验 → 有界重试 → 记账）。成功即变 **`REAL`**（以账本为证，不是配置自封）。
6. **跑一条真实任务**：回「制作」页，用一段两三百字的公开材料做「资料总结」。
   看到有内容的输出、且用量卡里出现这一次调用记录，文本链路就算通了。

百炼与硅基流动填法（接第 3 步）：

| 接入方式 | 端点 | 模型 |
| --- | --- | --- |
| 阿里云百炼 / 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-flash`（免费额度内）→ 想更好换 `qwen-plus` |

## 3. 免费额度够测多少（按本系统的实际请求量估）

本系统五类任务的输出上限：资料总结 600 tokens、研究报告与视频脚本约 1200–2000 tokens、
选题与英文文案约 800–1200；输入是材料正文（一次 1k–8k tokens 常见）。

| 任务 | 单次约消耗（输入+输出） | 智谱免费档 | 百炼 100 万 |
| --- | --- | --- | --- |
| 资料总结（3k 字材料） | ≈ 1.4 千 tokens | 不限量 | ≈ 500 次 |
| 研究报告（8k 字材料） | ≈ 5 千 tokens | 不限量 | ≈ 200 次 |
| 英文文案 / 选题 | ≈ 1.5 千 tokens | 不限量 | ≈ 600 次 |
| 连接测试 | ≈ 30 tokens | 不限量 | ≈ 3 万次 |

**判断标准**：一次端到端的「材料 → 研究报告 → 选题 → 英文文案」全链路，用百炼也在
**几千 tokens** 量级。100 万 tokens 足够你把提示词改上几十轮。

## 4. 图像免费档（智谱 CogView）

「图像生成」卡 → 接入方式 **智谱 CogView（有免费档）** → 端点 `https://open.bigmodel.cn/api/paas/v4`
→ 模型 `cogview-3-flash` → 填同一个智谱 Key。

与文本用同一个平台的好处：**一个账号、一次实名、一个 Key 覆盖文本 + 图像**。

> 图像适配器支持 `b64_json` 与 `url` 两种返回；CogView 返回 `url`，系统会**再过一次出站校验**
> 后下载落盘（不是裸取外部地址）。

## 5. 三个几乎一定会遇到的坑

### 5.1 报 `PROVIDER_EGRESS_BLOCKED`（被数据分级挡住）

**这不是接入失败，是安全策略在正常工作。** 分级规则里有几条很敏感：

- 出现 `内部资料 / 仅供内部 / confidential` → `INTERNAL`（允许外发）
- 出现 **邮箱地址、手机号、身份证、银行卡、客户名单、KYC** → `CONFIDENTIAL`（**默认禁止外发**）

营销文案里带一个 `name@brand.com` 或 `138xxxx` 就会被判机密。
**测试阶段**处理办法：用不含联系方式与客户信息的公开材料；确需用真实材料，
到「数据外发策略」卡显式开 `allowConfidential`（会在审计里留痕）。
**不要**为了测试方便去改分级规则。

### 5.2 报 `RATE_LIMITED` / HTTP 429

免费档限速是常态（百炼每分钟 20 次、并发 2）。系统会遵守 `Retry-After` 做**有界重试**
（最多 3 次、指数退避 400ms 起、封顶 8s）。仍失败就隔一分钟再点——**不要**把重试次数调到很大，
那只会把限速打得更久。

### 5.3 报 `model not found` / 400

模型名写错或该模型没有免费额度。**以控制台「模型广场」里显示的完整模型名为准**，
不要照抄博客。上面表格里的名字是 2026-10 核实的，厂商改名后请以控制台为准。

## 6. 什么时候才必须付费

| 场景 | 是否必须付费 |
| --- | --- |
| 五类文本产出、出图、改提示词、验收流程 | **否**（免费档够用） |
| **视频成片** | **是**（无免费档，按秒计费） |
| 多人并发使用、批量跑几十条 | 是（免费档会限速） |
| 正式对外发布的内容 | 建议付费档（免费档可能被用于服务优化，条款以厂商为准） |
| 需要稳定 SLA / 数据不用于训练 | 是（选企业版或私有化） |

**建议的推进顺序**：
① 智谱免费档跑通文本 + 图像 → ② 用真实材料评估输出质量（这一步决定你要不要换更贵的模型）→
③ 换成正式模型（百炼 `qwen-plus` / DeepSeek `deepseek-v4-pro`）→ ④ 最后再开视频。
付费的动作**只在第 ③ 步发生**，且换模型只需要改「接入方式 + 端点 + 模型」三个字段，**不用改代码**。

## 7. 想完全不注册也能先看流程？

「大语言模型」卡选 **`MOCK（演示用，非真实模型）`**，图像卡同样有 MOCK。
它会产出**确定性骨架**并显著标注 `mock:true`，用于走通「创作 → 审核 → 排期」的界面流程。

- MOCK **不是**模型能力，就绪度恒为 `NOT_CONFIGURED`，**永远不会**变成 `REAL`；
- MOCK 产物**不能**作为正式内容输出（正式输出门禁会拦）；
- 它证明的是"流程通"，不是"模型通"。两者不要混为一谈。
