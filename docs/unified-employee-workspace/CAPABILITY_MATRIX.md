# 实际能力与边界

“已接入”表示使用现有 MOS API 与隔离 JSON 真实读写，不表示真实外部服务已验收。没有为通过测试新增虚假成功状态。

| 工作区 / 入口 | 实际整合 | 当前边界 |
| --- | --- | --- |
| 工作台：我的工作 | 新任务工作面；今日、本周、本月、未来、紧急、逾期及收到提醒过滤 | 本轮用合成任务，不是员工生产待办 |
| 工作台：进行项目 | 复用活动/选题聚合，按当前品牌展示 | 不把可见的其他品牌数据混入当前列表 |
| 工作台：全部任务 | 复用完整任务表、筛选、临时任务及任务新建；打开后进入新作品流程 | 保留原任务字段与权限，未另建任务对象 |
| 工作台：待我审核 | 新冻结作品面，独立专业审核、发布审批及反馈 | 作者不能自审；入库最终审批是另外的权限 |
| 数据工作台：数据获取 | 情报流、来源、AI 研究、选题建议；关联专题、内容日历 | 隔离环境未配置真实搜索，不证明全网研究已验收 |
| 数据工作台：营销活动 | 活动实际创建、Brief、交付关联，VFIB / UCARD 工作区 | 不新增营销自动执行引擎 |
| 数据工作台：运营数据 | 复用内容、渠道、执行与调用账本分析 | 没有真实发布/费用记录时显示缺失，不造数据 |
| 内容制作：文字 | 自由对话、测试候选、选择正文并保存到同一任务，直接进入制作审核 | 只调用本地 Mock 文本；不是实际大模型输出 |
| 内容制作：图片 | 现有图片界面、提示词预览、工作素材上传；从任务进入带上任务关联，图片可选为审核附件 | 当前图片供应商未配置；没有声称真实文生图/图生图完成 |
| 内容制作：视频 | 任务简报、脚本、分镜、字幕、素材和成片上传的既有工作区 | 手工简报实际保存通过；真实文生/图生视频渲染未配置 |
| 发布管理：草稿箱 | 读取同一 content_versions，直接进入新作品面 | 不复制草稿库 |
| 发布管理：多平台发布 | 日历、队列、渠道、手动回执与归档的原功能 | 不执行真实社媒发布，不把排期当发布成功 |
| 品牌规范：品牌总览 | 品牌配置与授权资产查询的既有只读界面 | 资料库未配置时不伪造正式资产 |
| 品牌规范：内容规范 | 视觉、版式、内容规则和模板的原能力 | 未改资料库源码、未自动批准规则或模板 |
| 品牌规范：参考资料 | 既有受控查询；关联资产入库与治理 | 不绕过 Workspace 权限与独立入库审批 |
| 系统扩展：AI 管理 | 现有 Provider 状态、预算、策略和配置页面，仅管理员可见 | 测试环境不用正式密钥；真实调用与费用未验收 |
| 系统扩展：平台管理 | 真实渠道登记、多账号列表、同平台多账号 | 账号登记不等于 OAuth 登录；不保存社媒密码、不自动发布 |

全局保持品牌、会话、语言和原权限边界。普通员工显示六区结构，但系统管理按钮按权限隐藏；不存在通过前端切换角色获得权限的功能。

自由图片一键新建任务送审、真实研究报告生产、AI 图像/视频理解、真实社媒授权与发布，不能因界面已接入就被认为已完成。本轮优先让已有功能可统一试用，并打通有现成接口的文字、素材、视频、任务与审核衔接。
