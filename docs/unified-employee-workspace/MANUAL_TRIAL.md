# 如何测试完整工作区

当前是隔离合成环境。建议先用 `pilot_admin` 看完整入口，再用制作、专业审核、发布审批三个账号各走自己的工作。口令均为 `PilotTest2026A!`；请使用独立浏览器配置，以免共享 Cookie 切换身份。

## 第一轮：六区走查

| 步骤 | 入口与操作 | 应看到的结果 |
| --- | --- | --- |
| 1 | 管理员登录 → 我的工作 | 管理员走查任务；左侧六区可滚动查看，共 17 个主入口 |
| 2 | 进行项目 → 切换 VFIB / UCARD | 当前品牌活动，不串用另一品牌项目 |
| 3 | 全部任务 → 搜索、筛选、打开 | 原任务表与筛选可用，打开后进入同一任务的新制作面 |
| 4 | 数据获取 → 来源 / 研究 / 选题建议 | 真实读取服务端状态；未配置的研究通道明确阻断，不返回编造研究 |
| 5 | 营销活动 → 新建活动 | 活动保存后仍在列表；可进入品牌营销工作区 |
| 6 | 数据获取 → 内容日历 | 查看合成 11 月计划及日期格；切换周视图 |
| 7 | 文字制作区 → 输入两轮 → 选用保存到任务 | 保存选定正文，不保存整段聊天，直接打开正确任务 |
| 8 | 从该任务进入图片制作区 → 上传测试图片 → 返回任务 | 保留任务关联，图片可作为任务审核附件；不要把上传当作 AI 生成 |
| 9 | 视频制作区 → 改简报并保存 | 切页前有未保存确认；保存后重新打开仍在；未配置 AI 渲染不假装出片 |
| 10 | 草稿箱 → 打开作品 | 与任务中的 content_versions 相同，不是另外一份草稿 |
| 11 | 多平台发布 → 日历、队列、归档 | 原视图可用；没有真实发布记录时归档不造记录 |
| 12 | 品牌总览 / 内容规范 / 参考资料 | 查看规则及查询状态；未配置资料库时说明不可用 |
| 13 | AI 管理 / 平台管理 | 管理员可查配置；平台登记中有同平台多个合成账号，不代表真实登录 |

## 第二轮：员工闭环

1. `pilot_maker` 打开“按反馈修改服务问答”，读取合成反馈，创建修订、修改、保存、送审。
2. `pilot_professional` 在待我审核打开同一作品，批准或填具体意见退回。
3. 作者修改后重新提交，新版本不继承旧批准。
4. `pilot_publisher` 等专业审核通过后执行发布审批。最终应明确为已批准、尚未发布。
5. 取消离开未保存页面，确认文字或视频简报仍在；切换品牌与语言，确认没有串用任务或改写正文。

请记录卡住的位置、需要解释的按钮、误点、保存对象是否清楚，以及想完成但找不到的功能。自动浏览器检查不能替代这些真实观察。本轮没有声称员工体验或生产验收已经通过。
